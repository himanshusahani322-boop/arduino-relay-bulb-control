# Arduino Relay Bulb Control 💡

This project uses Arduino and a relay module to control an AC bulb.

## 🔧 Components Used
- Arduino UNO
- Relay Module
- Bulb
- Wires

## ⚙️ Working
Arduino sends signal to relay module.
Relay acts as a switch to turn ON/OFF the AC bulb.

## 🚀 Features
- Simple ON/OFF control
- Can be upgraded to IoT

- ## work like smart home automation
